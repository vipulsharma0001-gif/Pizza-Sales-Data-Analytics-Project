This project focuses on analyzing pizza sales data using SQL and data analytics techniques to uncover meaningful business insights. The analysis helps understand customer purchasing behavior, sales performance, revenue trends, and product demand patterns.

The project demonstrates practical knowledge of:

Data Cleaning
Exploratory Data Analysis (EDA)
SQL Querying
Business Intelligence
Data Visualization

The goal of this project is to transform raw sales data into actionable insights that can help improve decision-making and business growth.

Dataset

The dataset contains pizza sales transaction data, including:

Order Details
Pizza Types
Pizza Sizes
Categories
Quantities Sold
Revenue Information
Order Date & Time

The dataset was analyzed to identify:

Total orders and revenue
Best-selling pizzas
Customer ordering trends
Revenue contribution by pizza category
Peak sales hours and days
